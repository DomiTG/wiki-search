# WikiRace — Wikipedia Navigation Game

A competitive Wikipedia navigation game built with Next.js 14 (App Router) and TypeScript.

## How to Play

1. Start on a Wikipedia article
2. Navigate to the target article using only the links inside each page
3. No searching allowed — pure knowledge and intuition!

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Tech Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4** — dark mode by default
- **shadcn/ui** components (button, card, badge, dialog, tabs, etc.)
- **Radix UI** primitives

## Features

- 🎮 Solo & multiplayer lobby modes
- ⏱️ Configurable timer and click limits
- 🗺️ Live path breadcrumb
- 🏆 Victory modal with shareable results
- 🚫 Anti-cheat: Ctrl+F search blocked during play
